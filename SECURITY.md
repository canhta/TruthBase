# Security

TruthBase has no released runtime or supported production version yet. Its specification is not a security certification.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/canhta/TruthBase/security/advisories/new). Include the affected revision, reproduction with synthetic data, expected boundary and observed impact. Never put credentials, customer data or exploit details in a public issue.

Maintainers will assess the report and coordinate a fix and disclosure where applicable. No response-time or production support guarantee is currently offered.
